# Support

This file is the org default, for repos without their own support guide.
A repo guide, if it exists, wins over this file.

## Docs first

Start with the repo README, and the docs site.
Docs site: https://infralicious.github.io/
TrueTime docs: https://infralicious.github.io/truetime/
Search issues, before you open a new issue.

## Open an issue

Use an issue, for a bug, a feature request, or a question about code.
Use the issue templates, in the repo, or in the org defaults.
Describe the version, the steps, and the expected result.
A maintainer replies, when time allows, no SLA exists for free repos.

## Contact form

Use the contact form, for general contact, at https://infralicious.com/contact.html
Use the contact form, for security reports, see `SECURITY.md`.
Do not expect a phone reply, for free repos, unless a paid tier says otherwise.

## No support for

No support for forks, modified code, or old releases, unless stated otherwise.
No support for private installs, unless a maintainer agrees in writing.
