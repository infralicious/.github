# Infralicious

Infralicious builds small, useful tools, with a focus on security and reliability.
This org profile shows the main projects, and where to start.

## Projects

- TrueTime for Jira: Forge-native timesheets for Jira, free up to 10 users.
  - Docs: https://infralicious.github.io/truetime/
- actions-checkout: Checkout action, with persist-credentials false by default.
  - Marketplace: https://github.com/marketplace/actions/checkout-without-persisted-credentials
- Safe-settings admin: this repo, repo settings as code, for the whole org.
